# Third-party components

OmniDrop is MIT-licensed. It is built on the open-source components below; their licenses allow
redistribution in the installers published on the Releases page. This file is generated by
`node scripts/third-party.mjs` — the summary is maintained by hand in
`scripts/third-party-summary.md`. The inventories below cover every target platform (including
Tauri dependencies used only on other systems); each installer contains a subset.

## Not distributed: FFmpeg

Audio and video features use the FFmpeg already installed on the user's computer. OmniDrop does not
bundle, download or link FFmpeg. FFmpeg is licensed under the LGPL-2.1+ or GPL-2.0+ depending on how
it was built; those terms apply to the user's own FFmpeg installation.
